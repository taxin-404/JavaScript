# JavaScript

Practice projects for the project gallery.

Add projects under:

```text
projects/<category>/<project>/index.html
```

The gallery discovers every matching folder automatically. For example:

```text
projects/Basics/1_Counter/index.html
projects/DOM/1_Color_Changer/index.html
projects/Apps/1_Tip_Calculator/index.html
```

Each project can also include its own CSS, JavaScript, and image files. The gallery serves them through its preview proxy.
